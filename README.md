# Satsangs

Self-study slide decks for the fortnightly satsangs of the Ramakrishna Vedanta Centre NZ (27 Arawai Street, New Lynn, Auckland, and on Zoom).

Each folder is one satsang, named by its deck code (for example `SAT-DM-001`), and holds a self-contained web deck (`index.html`). Devotees go through the deck before the satsang; the session itself is given to questions, reflection and practice.

The library with summaries, reflection questions, recordings and the question form is at https://www.vedanta.nz/satsangs
